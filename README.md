# เว็บจำลองสั่งอาหารตี๋น้อย

เว็บจำลองแบบหลายหน้า ใช้ HTML, CSS, JavaScript และ Bootstrap 5.3.3 โดยบันทึกโต๊ะ แพ็กเกจ และตะกร้าไว้ใน localStorage เพื่อให้ข้อมูลอยู่ต่อเมื่อเปลี่ยนหน้า

## วิธีเปิดใช้งาน

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ที่เชื่อมต่ออินเทอร์เน็ต (ใช้ Bootstrap และแบบอักษรจาก CDN)

## ลำดับการใช้งาน

1. `auth.html` — ขอรหัสยืนยันแบบสุ่ม 6 หลักและกรอกรหัสเพื่อเข้าใช้งาน
2. `index.html` — หน้าหลักแนะนำระบบ
3. `package.html` — เลือกแพ็กเกจอาหาร
4. `table.html` — เลือกโต๊ะที่ว่าง
5. `menu.html` — เลือกเมนูและเพิ่มลงตะกร้า
6. `list.html` — ตรวจสอบรายการ ยืนยันออเดอร์ และดูเวลารอจำลอง 10–25 นาที

## โครงสร้างไฟล์

```text
webproject/
├── index.html                 # หน้าหลักแนะนำ
├── table.html                 # หน้าเลือกโต๊ะ
├── package.html               # หน้าเลือกแพ็กเกจ
├── menu.html                  # หน้าเลือกเมนู
├── list.html                  # หน้ายืนยันออเดอร์
├── auth.html                  # หน้ายืนยันตัวตนด้วยรหัส 6 หลัก
├── README.md                  # คู่มือโปรเจกต์
└── assets/
    ├── css/style.css          # รูปแบบและการรองรับมือถือ
    └── js/app.js              # ข้อมูลและฟังก์ชันของระบบ
```

ระบบนี้เป็นการจำลอง ไม่มีระบบหลังบ้าน การชำระเงินจริง หรือการส่งออเดอร์เข้าร้าน
